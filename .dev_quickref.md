# TomeNET Developer Quick Reference

## Build Commands
```bash
cd src
make                    # Build everything
make server             # Server only
make client             # Client only  
make accedit            # Account editor
make clean              # Clean build artifacts
make install            # Install to system (optional)
```

## Run Commands
```bash
./tomenet.server        # Start server (foreground)
./runserv               # Start server (script)
./tomenet               # Start client
./accedit               # Edit accounts
```

## Common Code Patterns

### Server: Iterate all players
```c
for (i = 1; i <= NumPlayers; i++) {
    p_ptr = Players[i];
    if (p_ptr->conn == NOT_CONNECTED) continue;
    // Do something with p_ptr
}
```

### Server: Send packet to player
```c
Packet_printf(&Conn[p_ptr->conn]->c, "%c%d%s", PKT_TYPE, value, string);
```

### Server: Execute Lua
```c
exec_lua(Ind, "lua_function()");              // Returns number
int result = exec_lua(0, "return value");     // Server context
cptr str = string_exec_lua(Ind, "return get_name()");  // Returns string
```

### Client: Draw to screen
```c
Term_draw(x, y, attr, char);                  // Single character
Term_text(x, y, n, attr, str);                // String
Term_fresh();                                 // Flush to screen
```

### Data structures: Accessing info arrays
```c
monster_race *r_ptr = &r_info[r_idx];         // Monster race
object_kind *k_ptr = &k_info[k_idx];          // Object kind
artifact_type *a_ptr = &a_info[a_idx];        // Artifact
```

## File Locations

### When you need to...

**Add a new monster**: Edit `lib/game/r_info.txt`, restart server  
**Add a new item**: Edit `lib/game/k_info.txt`, restart server  
**Add a new spell**: Edit `lib/scpt/s_*.lua`, use `/lua` or restart  
**Change server config**: Edit `lib/config/tomenet.cfg`, restart  
**Add player command**: Edit `src/server/cmd*.c`, rebuild server  
**Change network protocol**: Edit `src/server/nserver.c` + `src/client/nclient.c`, rebuild both  
**Modify UI**: Edit `src/client/main-*.c` and `z-term.c`, rebuild client  
**Add Lua API**: Edit `src/server/lua/*.pkg`, run tolua, rebuild  

## Debugging

### Server debug
```bash
gdb ./tomenet.server
(gdb) run
# When crashed:
(gdb) bt          # Backtrace
(gdb) info locals # Local variables
```

### Check logs
```bash
tail -f lib/data/tomenet.log        # Server log
tail -f lib/data/cheeze.log         # Exploit detection
less lib/data/legends.log           # Notable events
```

### Common issues

**Server won't start**: Check `lib/data/tomenet.pid`, remove if stale  
**Can't connect**: Check firewall, verify port in `tomenet.cfg`  
**Crash on data load**: Delete `.raw` files in `lib/data/`, let regenerate  
**Lua errors**: Check syntax, ensure files in `lib/scpt/` are readable  

## Network Protocol

### Adding new packet type

1. Define in `src/common/net-basics.h` or similar:
   ```c
   #define PKT_MY_NEW_PACKET 250
   ```

2. Server send in `src/server/*.c`:
   ```c
   Packet_printf(&Conn[p_ptr->conn]->c, "%c%d", PKT_MY_NEW_PACKET, data);
   ```

3. Client receive in `src/client/nclient.c`:
   ```c
   static int Receive_my_new_packet(void) {
       int data;
       if (Packet_scanf(&rbuf, "%c%d", &ch, &data) < 1) return 0;
       // Process data
       return 1;
   }
   ```

4. Register in `Setup_receive()`:
   ```c
   receive_tbl[PKT_MY_NEW_PACKET] = Receive_my_new_packet;
   ```

5. Rebuild both client and server

## Performance Tips

- Use `#ifdef DEBUG` for expensive debug code
- Avoid excessive `exec_lua()` calls in hot paths
- Network: Batch multiple values in single packet when possible
- Client: Minimize `Term_fresh()` calls, batch drawing

## Code Organization

### Naming conventions
- `p_ptr` - Player pointer
- `m_ptr` - Monster pointer  
- `o_ptr` - Object pointer
- `r_ptr` - Monster race pointer
- `k_ptr` - Object kind pointer
- `Ind` - Player index (1-based)
- `ind` - Connection index

### Common macros
- `C_MAKE(ptr, num, type)` - Allocate array
- `C_KILL(ptr, num, type)` - Free array
- `MAKE(ptr, type)` - Allocate single
- `KILL(ptr, type)` - Free single
