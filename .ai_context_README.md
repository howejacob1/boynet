# AI Assistant Context Files

This directory contains comprehensive indexing and reference files designed to help AI assistants quickly understand the TomeNET codebase.

## Files

### `.cursor_index.md` (Main Index)
**Purpose**: Comprehensive codebase overview with all major systems documented  
**Use case**: First read when starting a new conversation or context window  
**Contains**:
- Complete directory structure breakdown
- Core systems architecture (game loop, networking, rendering, Lua)
- Network protocol details (UDP reliability layer, packet types, connection flow)
- Lua scripting integration (initialization, execution model, hooks)
- Data file formats (parsing, structure, examples)
- Key file reference with line counts
- Build system overview
- Common globals and data structures
- Quick navigation guides

**Lines**: ~620 lines  
**Format**: Markdown with code examples

### `.dev_quickref.md` (Quick Reference)
**Purpose**: Fast lookup for common development tasks  
**Use case**: When you need to perform a specific task quickly  
**Contains**:
- Build commands (make targets)
- Common code patterns (iteration, packet sending, Lua calls)
- File locations for specific tasks
- Debugging commands and tips
- Network protocol addition guide
- Grep patterns for finding code
- Git workflow
- Performance tips

**Lines**: ~300 lines  
**Format**: Markdown with code snippets

### `DEVELOPMENT_REFERENCE.md` (Development Guide)
**Purpose**: Extended development practices and architecture notes  
**Use case**: Understanding development workflow and conventions  
**Contains**:
- Project overview
- Directory structure
- Build system details
- Network architecture (detailed)
- Lua integration (detailed)
- Data file format specifications
- Development practices
- Git workflow
- Common tasks

**Lines**: ~230 lines  
**Format**: Markdown

### `tags` (CTAGS Index)
**Purpose**: Symbol navigation for code editors  
**Use case**: Jump to function/variable definitions  
**Contains**: ~27,700+ symbol definitions from C/Lua source files  
**Format**: CTAGS format (etags compatible)

## Usage Recommendations

### For AI Assistants

**Starting a new conversation:**
1. Read `.cursor_index.md` first (comprehensive overview)
2. Optionally skim `.dev_quickref.md` for task patterns
3. Use `codebase_search` for specific questions
4. Use `grep` with patterns from quickref for symbol searches
5. Reference `DEVELOPMENT_REFERENCE.md` for detailed subsystem explanations

**For specific tasks:**
1. Check `.dev_quickref.md` for relevant pattern
2. Use `grep` or `codebase_search` to find implementation
3. Reference `.cursor_index.md` for context on system architecture

**For debugging:**
1. Check "Key Files Reference" in `.cursor_index.md` for relevant files
2. Use "Where to find..." section to locate functionality
3. Use `grep` patterns from `.dev_quickref.md`

### For Developers

**With a ctags-compatible editor (vim, emacs, etc.):**
```bash
# Navigate to symbol definition
:tag function_name     # vim
M-. function_name      # emacs
```

**Regenerating tags after changes:**
```bash
find . -path './.git' -prune -o -type f \
  \( -name '*.c' -o -name '*.h' -o -name '*.lua' \) \
  -print | ctags -
```

**Reading index files:**
- Use any markdown viewer or text editor
- Files are designed to be readable as plain text
- Search within files for specific topics
